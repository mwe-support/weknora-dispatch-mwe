# WeKnora v0.7.2 生产加固（2026-08-13）

## 发布范围

- 上游版本：WeKnora `v0.7.2`
- 定制仓库：`mwe-support/weknora-dispatch-mwe`
- 目标分支：`weknora-v0.7.2`
- MCP 专属代码：不包含；MCP 改动应进入 `weknora-mcp-dispatch`

## 变更摘要

### 腾讯文档附件同步兼容

- 腾讯文档数据源使用与知识入库统一的文件扩展名白名单。
- 支持通过导出/下载链路同步 PDF、PNG/JPG、Office、文本和音频等 WeKnora 已支持格式。
- 对不支持的资源类型给出明确的跳过/失败行为，避免数据源显示成功但实际没有入库内容。
- 增量同步、直选文档、文件夹范围和分页/游标路径均有回归覆盖。

### 部署级模型默认值

- API、MCP 和前端省略模型字段时，知识库自动继承部署的 Embedding、LLM 和 VLM 默认值。
- 智能体自动继承部署的 LLM、Rerank 和 VLM 默认值，并保留调用方显式指定的模型。
- 部署策略启用但缺少必需模型时失败关闭，避免生成无法索引或无法回答的半配置对象。
- 已有知识库或智能体读取时也能得到有效默认值。
- Embedding 模型解析失败时把知识状态持久化为 `failed`，不再长期停留在处理中。

### 数据源同步状态即时刷新

- 用户点击“立即同步”后立即进入乐观轮询。
- 新同步日志尚未可见时保持刷新；新日志出现后交给服务端状态继续驱动。
- 超过宽限期仍无日志时解除前端锁定，避免按钮永久显示同步中。

### 设置页面性能修复

- `/platform/settings` 使用路由内设置组件时，不再同时挂载全局设置组件。
- 其他平台页面继续保留唯一的全局设置宿主，避免 API、知识库设置和数据源页面重复渲染造成卡顿。

### 前端构建完整性门禁

- `npm run build` 和 `npm run build-only` 在 Vite 构建后扫描 HTML、JS、CSS 的静态资源引用。
- 缺失资源、空脚本或空样式会使构建失败，防止再次发布“页面可打开但分块 CSS 实际返回 index.html”的损坏镜像。

### 本批次同时包含的既有加固

- 新知识库解析规则按部署策略选择 MinerU、MarkItDown 与内置解析器。
- MinerU 响应兼容 filename-keyed、legacy `document/files` 和动态结果键，并拒绝最终空内容。

- 前端已验证桌面端关键路径；移动端和低频管理页面未逐页进行视觉回归。
- 工作树中的定制代码基于 `v0.7.2`，升级上游版本时必须重新执行完整的 Go、前端与真实数据源验收。
