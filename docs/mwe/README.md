# MWE WeKnora 定制发布记录

本目录记录 `mwe-support/weknora-dispatch-mwe` 的定制实现与生产验证，便于审计、升级和回滚。

## 发布记录规则

每次向版本分支推送一批定制代码前，必须在 `docs/mwe/releases/` 新增或更新一份记录，至少包含：

- 上游 WeKnora 版本、目标仓库和目标分支；
- 变更范围以及对应的逻辑提交；
- 问题根因或功能设计动机；
- 对用户、API、部署配置和数据兼容性的影响；
- 实际执行的测试、构建和生产验收结果；
- 生产镜像或发布标识、回滚点与残余风险。

一次推送批次对应一份汇总记录。记录不得包含凭证、签名 URL 或真实业务文档内容。
